# 🌱 ECOnomus - Educador Ambiental Virtual

Bem-vindo ao repositório oficial da landing page do **ECOnomus**! 

O ECOnomus é um chatbot desenvolvido no DialogFlow e integrado ao Telegram, projetado para atuar como um educador ambiental. Ele auxilia usuários com dicas de reciclagem, conceitos de sustentabilidade, pontos de coleta e muito mais.

## 🚀 Acesse o Bot
Você pode interagir com o ECOnomus diretamente no Telegram ou escanear o QR Code na página de divulgação.
👉 **[Clique aqui para conversar com o ECOnomus](https://t.me/ECOnomusBot)** *(Atualize com o link do seu bot)*

## 🖥️ Sobre a Landing Page
Esta página foi criada para divulgar o projeto, oferecendo um acesso rápido e fácil ao bot. 
- **Design:** Focado na experiência do usuário, com tema *Dark Mode* e identidade visual voltada para a natureza e tecnologia.
- **Tecnologias:** HTML5 e CSS3 (hospedado via GitHub Pages).

## 🌐 Acesse a Página

👉 **[ECOnomus no GitHub Pages](https://JoCa-SP.github.io/ECOnomus/)** *(Atualize com o seu link real)*

## 🛠️ Como rodar o projeto localmente
1. Faça o clone deste repositório.
2. Abra o arquivo `index.html` em qualquer navegador de sua preferência.
3. Lembre-se de alterar o link do Telegram no código caso deseje apontar para outro bot.
